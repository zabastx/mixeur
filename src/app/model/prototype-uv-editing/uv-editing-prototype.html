Can Mixeur do Blender-style UV editing?

This demo pushes a real THREE.BufferGeometry UV layout — the exact vertex splitting Mixeur's primitives produce — through the operations a UV editor needs: select, move, rotate, scale, weld. The mesh on the right re-textures live off the same buffer you are editing on the left.

The question is not "does dragging a point work". It is what a UV selection is made of: a mesh vertex can own several UV coordinates, so "select this corner and move it" has three defensible answers, and picking the wrong one is how a UV editor ends up feeling broken.
